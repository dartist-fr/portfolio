# France — Sud

Dépose ici les photos de la série Sud.

## Ajouter des photos

1. Ajoute les fichiers image dans ce dossier.
2. Envoie les changements sur la branche `main`.
3. Le workflow **Actualiser le portfolio** convertit les JPG/JPEG en WebP puis actualise automatiquement `images-manifest.json`.
4. Vérifie le résultat dans [Actions](https://github.com/dartist-fr/portfolio/actions), puis sur le [portfolio en ligne](https://dartist-fr.github.io/portfolio/).

Il n’est pas nécessaire de modifier `index.html` ni d’ajouter manuellement les chemins dans le manifeste. L’ordre des photos déjà publiées est conservé et les nouvelles images sont ajoutées à la fin. La couverture existante est conservée tant que son fichier est présent.

Formats reconnus : JPG, JPEG, PNG, WebP, AVIF et GIF. Évite les doublons de fichiers et conserve des noms de fichiers explicites.
