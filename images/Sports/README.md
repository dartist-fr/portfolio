# Série Sports

Ce dossier regroupe les sous-séries photographiques sportives. Chaque discipline dispose de son propre sous-dossier.

## Ajouter une sous-série ou des photos

1. Pour une nouvelle discipline, crée un sous-dossier dans `images/Sports/`.
2. Ajoute les photos dans le dossier de la discipline concernée.
3. Envoie les changements sur la branche `main`.
4. Le workflow **Actualiser le portfolio** convertit les JPG/JPEG en WebP puis actualise automatiquement `images-manifest.json`.
5. Vérifie le résultat dans [Actions](https://github.com/dartist-fr/portfolio/actions), puis sur le [portfolio en ligne](https://dartist-fr.github.io/portfolio/).

Il n’est pas nécessaire de modifier `index.html` ni d’éditer manuellement le manifeste. Les dossiers deviennent des sous-séries et les couvertures existantes restent choisies tant que leurs fichiers sont présents.

Formats reconnus : JPG, JPEG, PNG, WebP, AVIF et GIF.
